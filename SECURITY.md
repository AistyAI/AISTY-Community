# Security policy

## Reporting a vulnerability

Email [security@aisty.ai](mailto:security@aisty.ai). Please do not open a public issue.

Include the version (or image tag), what you found, and steps to reproduce. We aim
to acknowledge reports within two working days and keep you updated until the fix
ships. We credit reporters in the release notes unless you ask us not to.

## Supported versions

Security fixes go into the latest minor release. Run a current release and
watch this repository's releases to hear about fixes.

## Scope

In scope: this repository and the `ghcr.io/aistyai/aisty-community` image.
Hosted Aisty and the Aisty Identity Service are covered by the same address.
