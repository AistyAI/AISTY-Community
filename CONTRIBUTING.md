# Contributing

Thanks for helping improve Aisty Community.

- **Bugs and ideas**: open an [issue](https://github.com/AistyAI/AISTY-Community/issues). For security problems, follow [SECURITY.md](SECURITY.md) instead.
- **Pull requests**: open an issue first for anything larger than a small fix, so we can agree the approach.

## Before you open a pull request

Run the checks from the [README](README.md#development): `check-no-paid-code`, the API tests, and the web lint and tests. CI runs the same steps and builds the image.

Keep changes focused, follow the existing style, and keep files under about 400 lines.
